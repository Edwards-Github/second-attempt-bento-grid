## My process

### Built with

- Semantic HTML5 markup
- CSS custom properties
- CSS Grid
- Mobile-first workflow

### What I learned

1. I learned about using @layer
2. I learned how to better organize my variables
3. I learned how to select individual boxes without using classes using nth-child instead of needlessly making classes for all of them.
4. I learned how to add default values for variables (i.e. max-width: var(--bento-card-image-width, 100%);)


### Continued development

1. I want to continue using this format of selecting each boxes or containers when I don't need to create classes. It creates a clean and simple way of customizing css values to each.

### Useful resources

- [Responsive Bento Grid by Kevin Powell](https://www.youtube.com/watch?v=h4dHvo09cG4) - This helped me understand how to start by looking at the design, organizing the html structure as well as the thought behind it, and also learn a new way of organizing the CSS.
